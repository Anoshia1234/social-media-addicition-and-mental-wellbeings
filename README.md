# 📱 Social Media Addiction & Mental Wellbeing Dashboard

An interactive, data-driven web application built with **Streamlit** and **Plotly** to analyze the profound relationship between social media usage behaviors, demographic patterns, platform dependencies, and user mental wellbeing.

🔗 **Live Streamlit Dashboard:** [View Live App](https://social-media-addiction-and-mental-wellbeings.streamlit.app/)

---

## 🌟 Key Features

* **🎨 Executive Sky-Blue UI/UX:** Designed with a professional sky-blue and deep navy color palette, custom CSS card layouts, and responsive typography (`Plus Jakarta Sans`).
* **🌐 Brand Visualizations:** Features official social media platform icons (Instagram, TikTok, YouTube, Facebook, Twitter/X, Snapchat) with live engagement metrics.
* **📊 Comprehensive Analytics:**
  1. **Addiction Severity by Platform:** Identifies which app harbors the highest concentration of high and severe addiction users.
  2. **Gender Usage Patterns:** Compares daily screen time and platform preferences between male and female users.
  3. **Occupational Insights:** Evaluates usage intensity and psychological impacts across **Students** vs. **Working Professionals**.
* **🎛️ Dynamic Sidebar Filtering:** Filter data in real-time by social media platforms, gender categories, occupation types, and age brackets.
* **📋 Summary Data Table:** Interactive aggregate table displaying key scores (Anxiety, Sleep Hours, Wellbeing, and Addiction Rates per platform).

---

## 🛠️ Tech Stack & Libraries

* **Python** (Core logic and data preprocessing)
* **Streamlit** (Web application framework)
* **Pandas** (Data manipulation and cleaning)
* **Plotly Express** (Interactive charts and visualizations)
* **FontAwesome** (Social media brand icons)
